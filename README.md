# Fieldwork

Fieldwork is a collection of small, reproducible technical investigations.
Each experiment asks one focused question, answers it through a working build,
and preserves runnable checkpoints so a reader can follow the discovery rather
than seeing only the finished code.

## Experiments

- [No-IP Chat](experiments/no-ip-chat/README.md) — can computers discover one
  another and chat through a switch without using IP?

## Reproducibility

Each published checkpoint is an immutable Git tag and GitHub pre-release. Its
documentation states the supported environment, commands, expected evidence,
and known limitations. A checkpoint is published only after it works from a
clean checkout.
